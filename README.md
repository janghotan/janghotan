### 👋 About

I build **applications and agents on top of existing LLMs** — not training models, but making them useful: tool use, local MCP servers, computer-use agents, and secure developer tooling.

- 🔭 Currently building **[local-mcp](https://github.com/janghotan/local-mcp)** — a modular, security-first local MCP server for Fedora/Sway (Phase 5: Data module)
- 🧪 Also working on a **learn-from-demo computer-use agent** that runs tasks in a background virtual desktop
- 🎯 Targeting roles as an **AI Application / Agent Developer**
- 💻 Daily driver: ThinkPad E14, freshly configured **Fedora + Sway**
